Steam Workshop upload
=====================

Upload the contents of this jenga folder as the Workshop mod.

Do not include:
- jenga-twitch-bridge
- JENGA_Twitch_Connector
- node_modules
- config.json

The base mod works standalone with Random and Normal modes.

GitHub users can add Twitch support later by installing:
- mods/jenga-twitch-bridge
- JENGA_Twitch_Connector

The Workshop jenga folder remains the same.


v0.8.20:
If Twitch was previously selected and the optional bridge is later disabled,
JENGA changes the mode to Normal when the next run starts.
